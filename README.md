# FNF Mic Link — downloads & updates

Official builds of **FNF Mic Link** — Psych Engine for Android with online play.

### [⬇ Download the latest version](https://github.com/bfgdesignerdev/FNF-Mic-Link-Update/releases/latest)

**Install:** download `FNF-Mic-Link-x.x.x.apk` from the latest release and open it.
If Android asks, allow installing apps from your browser.

**Updates:** starting with 1.1.6 the game updates itself — a red icon appears in the main menu
when a new version is out. Tap it to see what's new and press **UPDATE**.

News: [t.me/FNFMicLink](https://t.me/FNFMicLink)

---

### По-русски
Скачай `FNF-Mic-Link-x.x.x.apk` из [последнего релиза](https://github.com/bfgdesignerdev/FNF-Mic-Link-Update/releases/latest) и открой его.
С версии 1.1.6 игра обновляется сама: в главном меню появится красная иконка, нажми её → **UPDATE**.

---

<sub>`update.json` is read by the game's updater: the newest `versionCode`, the APK link, its size and SHA-256, and the change notes.</sub>
